MAISON SUCRÉ — WEBSITE + CHATBOX MÔ PHỎNG + VIDEO

Cách xem nhanh:
1. Giải nén file ZIP.
2. Mở thư mục maison_sucre_chatbox_package.
3. Nhấp đúp index.html để mở bằng Chrome.
4. Video ở phần “Behind Every Bite” dùng file assets/bakery.mp4. Hãy giữ nguyên thư mục assets cạnh index.html để video hiển thị.

Chatbox là mô phỏng theo kịch bản, không cần API hoặc server.
